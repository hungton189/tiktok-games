# Nhạc nền của bạn (tuỳ chọn)

Mặc định game dùng **nhạc tự tạo**. Trình duyệt tự soạn nhạc lúc chạy, nên không dính bản quyền.

Muốn dùng file nhạc riêng thì làm như sau:

1. Bỏ file `.mp3` / `.ogg` / `.wav` / `.m4a` vào:
   - `music/aquarium/`: nhạc cho Bể cá
   - `music/race/`: nhạc cho Đua thú
   - `music/shared/`: dùng cho mọi game chưa có thư mục riêng
2. Vào Admin → Nhạc nền → chọn **File nhạc của tôi** → bấm **Quét lại thư mục nhạc**.

Các bài được phát ngẫu nhiên và lặp lại.

⚠️ **Chỉ dùng nhạc bạn có quyền phát trên live**, ví dụ nhạc miễn phí bản quyền có giấy phép cho phép livestream, hoặc nhạc bạn tự làm. Nhạc có bản quyền có thể bị TikTok tắt tiếng hoặc gây gậy cho phiên live.
